# Costs and approvals

| Item | Cost | Needed? |
|---|---|---|
| HyperFrames, VideoHub, FFmpeg, Node, Python, faster-whisper, Three.js, GSAP, fonts (OFL), Natural Earth | free / open source | yes |
| Claude (Claude Code on the web or desktop) | your Claude plan | yes (the orchestrator) |
| Openverse, NASA, Wikimedia, Pexels, Pixabay media | free (Pexels/Pixabay need free keys) | recommended |
| Synthesised SFX, procedural music bed | free (original) | default |
| Licensed music (your library, e.g. YouTube Audio Library tracks with their licence noted) | free | recommended for publishing |
| Google Drive API | free (your storage) | for large uploads |
| Google Cloud Run render backend | ≈ $0.10–0.30 compute per 10-min video (estimate; free tier likely covers low volume) | optional |
| HeyGen hosted rendering / AI image / AI music services | paid plans or credits | optional, only with approval |
| Paid stock footage | per asset/subscription | only with approval |

The system asks before anything paid: it states what it is, why, the approximate cost, the free alternative,
and whether it is essential. Budget alerts are required before any cloud deployment.
