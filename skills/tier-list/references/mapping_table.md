## Choice order when several fit
1. If the script line quotes or sets up the person's own words and a clip exists, use row 10 (VO-off).
2. A verdict always gets row 19, nothing else.
3. Otherwise use the row for the most specific noun in the clause (person > item > place > brand > number).
4. Every new item gets row 3 on its first shot. The badge then persists on every shot of that item.
